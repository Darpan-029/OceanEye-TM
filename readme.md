# OceanEye — Eyes Beneath the Waves
> Production-grade Marine Intelligence & Ecosystem Command Platform

OceanEye is an AI-powered marine intelligence platform designed for researchers, NGOs, environmental agencies, and oceanic authorities to monitor, analyze, and protect marine ecosystems.

---

## Key Features

- **Immersive Ocean Dive Landing Experience (0 ft → 35,000 ft)**:
  - Scroll-linked vertical camera descent through scientifically accurate ocean zones (Epipelagic, Mesopelagic, Bathypelagic, Hadal).
  - Fixed depth indicator ruler, dark blue/bioluminescent gradients, marine snow particle canvas, educational micro-stories, feature reveals, and audio wave synthesizer.
- **Mission Control Central Dashboard**:
  - Interactive dark Leaflet ocean map with drone markers, oil spill indicators, coral reefs, species sightings, live telemetry timeline, hero KPIs with sparklines, and oceanographic weather panel.
- **VisionAI Pollution Detection**:
  - Deep Learning computer vision model detection feed with bounding box overlays, confidence score progress rings, category filters, and mitigation recommendations.
- **CoralScan Reef Sanctuary Monitor**:
  - Multispectral reef health scoring, thermal stress auditing, bleaching percentage risk tracking, and satellite image comparison.
- **Marine Biodiversity Census**:
  - Species tracking catalog, endangered status badges, migration telemetry, population trend graphs, and detail modals.
- **Ocean Atlas GIS Command**:
  - Multi-layer GIS platform, sector polygon selection, coordinate exporter (GeoJSON), and sanctuary boundary overlays.
- **Fleet Monitor & Telemetry**:
  - Underwater drone management (DR-001 through DR-006), battery level, current depth, speed, signal quality, and simulated optical camera streams.
- **AI Environmental Risk Engine**:
  - Predictive threat forecasting for oil slick dispersal, coral thermal stress, and storm trajectories with automated mitigation recommendations.
- **Analytics & BI Dashboard**:
  - Interactive Recharts area, line, and bar graphs for multi-year trends, export options (CSV).
- **Command Palette (`Ctrl+K` / `⌘+K`)**:
  - Instant keyboard fuzzy search across all species, drones, sectors, alerts, and navigation routes.
- **Clean Architecture Node.js/Express Backend (`/api/v1/`)**:
  - RESTful API endpoints, standardized response envelope with ISO timestamps, latency simulation, error handling, mock JSON repository layer, and Mongoose schema templates ready for MongoDB deployment.
